# PRODIGY_ML_01

## House Price Prediction using Linear Regression

### Internship

Prodigy InfoTech Machine Learning Internship

### Objective

Build a Linear Regression model to predict house prices based on:

* GrLivArea (Living Area)
* BedroomAbvGr (Number of Bedrooms)
* FullBath (Number of Bathrooms)

### Technologies Used

* Python
* Pandas
* Scikit-learn

### Dataset

House Prices - Advanced Regression Techniques Dataset from Kaggle

### Steps Performed

1. Loaded the dataset using Pandas
2. Selected important features
3. Trained a Linear Regression model
4. Predicted house prices

### Sample Prediction

For a house with:

* Area = 2000 sq ft
* Bedrooms = 3
* Bathrooms = 2

Predicted Price:
243444.31
